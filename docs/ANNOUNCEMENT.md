# 🚀 Vice 0.2.0: Mission Accomplished! The Final Chapter & A Huge Thank You

Hey everyone,

After **nearly two years of intense work, countless late nights, and heavy pair-programming with AI**, I'm both proud and relieved to announce that **Vice 0.2.0 is officially finished**.

When I started this project, people told me building a programming language from scratch in Rust was crazy — especially as a solo developer. But I wanted to understand how compilers, parsers, and virtual machines actually tick under the hood. 

What started as an experimental, tree-walking prototype has grown into a mature, statically-checked language running on its own custom bytecode VM, packed with built-in matrix math, a native Windows GUI installer, and over 50 automated test suites.

With the 0.2.0 release, **Vice has achieved everything I set out to build**. I am officially closing active development and archiving the project as feature-complete.

### 📦 Where to Find Vice 0.2.0

The project is completely open source and will remain permanently accessible:

- **GitHub Repository**: The entire codebase, complete git history, test suites, and documentation are live on GitHub. If you're learning Rust or curious about building your own bytecode VM, feel free to clone it, poke around, and use it as a learning reference.
- **Releases & Downloads**: Pre-compiled binaries for Windows x64 (`vice.exe` and `ViceInstaller.exe`) are available on the GitHub Releases page and in the release package.
- **Documentation**: All developer and student manuals remain preserved in the repo for anyone interested in the language's internals.
